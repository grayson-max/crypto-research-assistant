Crypto Research Brief · Setup Guide

You don't need to know anything about coding or AI to follow this. Do each step in order — it takes about 10 minutes. This only works on a Mac.

  • 1 Setting it up — first-time install
  • 2 Changing settings later — schedule time, delivery folder
  • 3 Changing what's in the brief — new data, charts, wording
  • 4 Taking it off your computer — safe, asks before deleting anything
  • 5 Common problems and fixes — what to check, in order
1

Setting it up

1

Open Terminal

Terminal is an app already on your Mac — it lets you type commands instead of clicking things.

  1. Press ⌘ Command + Space at the same time. A search box pops up.
  2. Type Terminal
  3. Press Enter

A plain window will open, showing some text ending in a $. That's where you'll type everything below.

2

Get two accounts set up

Before installing anything, you need two "keys" — think of a key as a password that lets this tool fetch data on your behalf.

Key 1 — Anthropic (this is what writes the brief itself)

  1. Go to console.anthropic.com and sign up.
  2. You'll need to add a card.
    Cost: pay-as-you-go, but one short brief a day typically runs a few cents a month.
  3. Find "API Keys" in the left-hand menu, click "Create Key", and copy the long string it gives you. Paste it somewhere temporary (like Notes) — you'll need it again in Step 4.

Key 2 — NewsAPI (finds headlines — free)

  1. Go to newsapi.org/register and sign up.
  2. Copy your API key from your account page and save it next to the first one.
3

Get the project onto your computer

You should have received a file called crypto_research_assistant.zip (by AirDrop, email, or a file-sharing link).

  1. Find it in your Downloads folder and double-click it — it unzips into a regular folder named crypto_research_assistant.
  2. Move that folder somewhere you'll remember — your Home folder (the one with the little house icon in Finder) is a good default.
    Don't put it inside Desktop, Documents, or Downloads. macOS blocks background scheduling from touching files in those three folders unless you separately grant access in System Settings, so the daily automatic brief would silently stop working with no error message telling you why. Your Home folder itself, or any other regular folder, is fine.
  3. Back in Terminal, move into that folder by typing:
$ cd crypto_research_assistant

If Terminal says "No such file or directory," the folder likely landed somewhere else — type cd (with a trailing space, no Enter yet), then drag the folder from Finder into the Terminal window, which fills in the correct path for you.

4

Run the installer

In Terminal, run it by typing:

$ ./install.sh
  1. It'll ask a series of questions, one at a time. Type your answer and press Enter — or if you see something in [brackets], pressing Enter alone uses that as the default.
  2. When asked for your Anthropic or NewsAPI key, paste the one you saved in Step 2 (⌘ + V) and press Enter.
  3. It checks that both keys actually work. If one fails, it'll say clearly which — usually a typo. Run ./install.sh again to retry.
  4. When you see === Setup complete ===, you're done.

What happens now

Every day at the time you chose (8:00 AM by default), this automatically:

  • Checks today's crypto prices and news
  • Has Claude write a short brief about it
  • Saves a nicely formatted copy into your iCloud Drive, in a folder called CryptoBriefs (or whatever name you chose)

You don't need to keep Terminal open — it runs on its own, as long as your Mac isn't asleep or off.

Want a brief right now instead of waiting? Run it by typing:

$ .venv/bin/python3 main.py

Want to change the schedule or delivery folder later? See 2 below.

2

Changing settings later

Want to change what time the brief runs, or the iCloud Drive folder it's delivered to? You don't need to reinstall anything.

1

Open Terminal and go to the project folder

$ cd crypto_research_assistant
2

Run the settings tool

$ ./configure.sh

It first shows what's currently set:

Current settings:
Coins tracked: BTC, ETH, SOL
Schedule time: 08:00
Delivery folder (iCloud Drive): CryptoBriefs

Then it asks two questions, each showing the current value in brackets:

  • New schedule time: type a new time in 24-hour format (e.g. 17:30 for 5:30 PM) and press Enter — or just press Enter alone to leave it unchanged.
  • New delivery folder name: same idea — type a new name, or press Enter to keep the current one.

It saves your answers and reschedules the daily run automatically — nothing else needs restarting, and your saved keys and past briefs are untouched.

Example

To move the daily brief from 8:00 AM to 5:30 PM: run ./configure.sh, type 17:30 at the schedule prompt, then press Enter at the folder prompt to leave it as-is.

Changing which coins are tracked isn't a guided prompt yet — that means editing a settings file directly, which is more technical. Ask whoever set this up for you if you need that changed.

3

Changing what's in the brief

Everything above covers running the brief as it already is. If you want it to actually say or show something different — track one more data point, add a small chart, shorten a section — that's not a settings toggle like 2. It's a small code change, and the easiest way to make one without learning to code yourself is to ask an AI assistant called Claude Code to make it for you, in plain English.

1

What Claude Code actually is

Think of it like texting a request to someone who can read and edit this project's code — except instead of a person, it's Claude (the same AI that writes the brief itself), and instead of texting, you type in Terminal. You describe what you want changed in plain English; it makes the change and tells you what it did.

2

Install it (one time)

  1. Go to claude.com/claude-code in your browser and follow the install instructions there for your Mac.
  2. You'll need your own Claude account to use it — separate from the Anthropic key from 1, Step 2. That key only lets the pipeline silently call Claude in the background; using Claude Code is you directly chatting with it, a different kind of access.
3

Open it inside this project

  1. Open Terminal and go to the project folder, same as always, by typing:
$ cd crypto_research_assistant

and press Enter.

  1. As a separate action, type:
$ claude

and press Enter. Wait for it to start up — you'll see a prompt where you can type a message.

4

Ask for the change, in plain English

Just describe what you want. Some examples:

  • "Add a data point showing each coin's 7-day trading volume trend."
  • "Add a small chart showing Bitcoin's price over the last 7 days."
  • "Make the headlines section shorter — 2 items per coin instead of 4."

It may ask a clarifying question or show you what it's about to change before doing it — that's normal, just answer or confirm.

5

See the result

Ask it directly: "Regenerate today's brief so I can see the change." It'll run the pipeline, and you can check the result the same way as always — in reports/ or the delivered copy in iCloud Drive.

If you don't like the result

Just say so — "undo that last change" works, because this project folder is tracked with a tool called git that remembers every past version, like a safety net. Nothing you ask for here is permanent or risky to try.

4

Taking it off your computer

If you ever want to stop this — for any reason, no explanation needed — here's how. It's built to be careful about not deleting things you might want to keep.

1

Open Terminal and go to the project folder

$ cd crypto_research_assistant

If you get an error saying that folder doesn't exist, it may be somewhere else — ask whoever set this up where it's located.

2

Run the uninstaller

$ ./uninstall.sh

It immediately turns off the daily automatic brief — no questions asked, since that part is completely safe to undo (just run ./install.sh again).

Then it asks three separate yes/no questions, one at a time, about whether to also delete:

  • Some technical setup files (fine to delete — y)
  • Your saved keys/settings (say n if you might reinstall later)
  • Your saved past briefs (say n if you want to keep reading them)

Type y + Enter for yes, n + Enter for no — or just press Enter alone for "no," the safe default.

What's left afterward

The project folder itself stays on your computer either way — nothing here deletes it automatically. If you want it gone completely, drag the crypto_research_assistant folder to the Trash yourself, same as any other folder.

5

Common problems and how to fix them

Nothing here can damage your computer — worst case, a brief doesn't get generated one day. Here's what's most likely to come up, and exactly what to do.

"Permission denied" when running ./install.sh (or any ./ command)

This means the file isn't marked as "runnable" yet. Fix it once with:

$ chmod +x install.sh configure.sh uninstall.sh

Then try the original command again.

macOS pops up asking for permission to access files/folders

The first time these scripts touch iCloud Drive or your saved settings, macOS may ask something like "Terminal" wants access to files in your Documents folder. Click OK or Allow — this is expected and required for briefs to be delivered.

If you accidentally clicked Don't Allow and things stopped working: go to System Settings → Privacy & Security → Files and Folders (on some macOS versions: Full Disk Access), find Terminal in the list, and turn it on.

During install, it says a key "failed to validate"

  • Anthropic key failed: usually a copy/paste typo (go back to console.anthropic.com and copy it again, carefully — no extra spaces), or a payment method hasn't been added yet on that site — the key won't work until billing is set up, even though the actual cost is small.
  • NewsAPI key failed: almost always a typo — go back to your NewsAPI account page and copy it again.

After fixing it, run ./install.sh again — it's safe to re-run and won't duplicate anything already set up.

No brief showed up today

Check these in order:

  1. Was your Mac asleep or off around the scheduled time (and for the 30 minutes after)? If so, it catches up automatically next time your Mac is awake — no action needed.
  2. Look at the log file for an error. In Finder, open the crypto_research_assistant folder, find cron.log, and double-click to open it in TextEdit. Scroll to the bottom (most recent entry) and look for:
    • "timeout" or "connection" → the internet was briefly down. Safe to ignore — it'll succeed next run, or generate one manually (see 1).
    • "401" or "authentication" near "anthropic" → your Anthropic key expired or billing lapsed. Fix it at console.anthropic.com, then generate a brief manually to confirm.
    • "Missing required API key(s)" → your saved keys file is missing or got moved. Run ./install.sh again to re-enter them.
  3. Check iCloud Drive is turned on: System Settings → your name at the top → iCloud → iCloud Drive. Without it, briefs still generate and save on this Mac, they just won't sync to your phone or other devices.

It's generating briefs, but they're not showing up on my phone/other devices

That's almost always the iCloud Drive check above — the brief is being created fine, it just isn't syncing anywhere else yet.

None of the above matches what you're seeing

Copy the exact text Terminal (or cron.log) showed you and send it to whoever gave you this project.
